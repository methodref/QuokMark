<h1 align="center">QuokMark</h1>
<p align="center">用熟悉的 Vim 快捷键，轻松访问和整理书签。</p>

本仓库公开可直接加载的 Chrome / Edge 扩展源码。`extension/` 是完整的插件目录，无需安装依赖或构建。

## 功能

- **快速访问**：`hjkl` 或方向键移动，`f` 字母选择，`Enter` 打开书签。
- **名称搜索**：搜索书签和文件夹，结果按目录分组展示。
- **书签管理**：重命名、修改链接、移动、排序与删除，直接使用浏览器原生书签。
- **导入与导出**：支持 JSON、Markdown 嵌套列表及浏览器书签 HTML，跨目录多选导出。
- **键盘操作**：目录折叠、半页滚动、复制网址，无需频繁切换鼠标。
- **日间与夜间**：自动跟随系统，也可以手动切换。
- **八种语言**：简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español。

## 安装

1. 下载本仓库并解压。
2. 打开 `edge://extensions` 或 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载解压缩的扩展」，选择 **extension** 文件夹。
4. 将 QuokMark 固定到浏览器工具栏。

Firefox 桌面版使用单独的 Firefox 安装包，当前 `extension/` 清单仅用于 Chrome / Edge。Firefox 版尚未上架扩展市场。

## 使用

按 **Command+E（macOS）** 或 **Ctrl+E（Windows）** 打开弹窗，也可以点击工具栏图标。若快捷键冲突，可在浏览器扩展的「键盘快捷键」页面修改。

| 按键 | 操作 |
| --- | --- |
| `hjkl` / 方向键 | 移动焦点；`h/l` 折叠或展开目录 |
| `/` | 搜索书签或文件夹名称 |
| `f` → 提示字母 | 打开对应书签 |
| `Enter` | 打开选中的书签 |
| `d/u` · `gg/G` | 下 / 上翻半页；跳到首项 / 末项 |
| `zc/zo` · `zM/zR` | 折叠 / 展开当前目录；折叠 / 展开所有目录 |
| `yy` | 复制书签网址 |
| `m` / 右键 | 重命名、修改链接、移动、调整顺序、删除 |
| `:` | 输入导入或导出命令 |
| `Esc` | 退出当前状态；非搜索时关闭主弹窗 |
| `?` | 查看帮助，切换语言和主题 |

重新打开弹窗会恢复上次选择，并将其定位在顶部约 1/3 处，尽量保留完整的顶部条目。

搜索时按一次 `Esc` 保留结果，再按一次清空搜索。输入完整字母标签会立即在新标签页打开书签。管理操作直接修改原生书签，删除前请确认。

## 调整顺序

选中条目后按 `m` 或右键，选择 **调整顺序…**：列表中直接选择同目录下的同类参照条目，放到它前面或后面，保存前可查看调整后的序号。支持 `j/k`（或上下方向键）选择、`h/l`（或左右方向键）切换前后、`d/u` 向下／向上翻半页、`gg/G` 跳到首尾、`Enter` 保存、`Esc` 取消，也可直接点击操作。位置未改变时不可保存。书签和目录分别排序，跨目录仍使用“移动到…”。

## 导入与导出

导入、导出通过 Vim 风格命令进入。在导航模式按 `:`，输入命令后按 `Enter`：

| 命令 | 操作 |
| --- | --- |
| `:r` / `:read` / `:import` | 导入书签，选择文件和目标目录 |
| `:w` / `:write` / `:export` | 选择目录，再选择导出格式 |
| `:w json` | 预选 JSON 格式 |
| `:w md` | 预选 Markdown 格式 |
| `:w html` | 预选浏览器书签 HTML 格式 |

导出别名也支持格式参数，例如 `:export md`。命令栏中 `Tab` 补全命令或格式，`Shift+Tab` 反向补全，`Esc` 返回导航模式。

导出目录树中使用 `j/k`（或上下方向键）移动、`h/l`（或左右方向键）折叠/展开、空格勾选或取消。可跨父目录选择，包含完整子树，不重复导出已包含的后代；同名目录保留必要的来源父目录结构。按 `Enter` 进入格式选择，若命令已指定格式则进入导出确认。格式控件可用 `j/k` 选择，`Enter` 进入确认按钮，再按 `Enter` 导出。

导入默认使用当前目录；选中书签时使用它所属的目录，也可以更换目标。文件读取后焦点进入目标目录控件，可用 `j/k` 选择，`Enter` 进入重复项处理或导入确认。仅检查目标目录下的重复项，书签按网址、目录按名称匹配；一次选择全部跳过或全部覆盖。不重复的条目追加到末尾。

覆盖重复目录会删除原目录及其全部内容，用文件内容完整替换，不合并；覆盖前列出将删除的书签和子目录数量。重复书签更新名称，重复目录保留原来的位置，目录内部采用文件顺序。每个目录替换先创建新子树，再删除旧目录；批量导入中断时，已完成的条目可能保留，请按提示检查后再导入。

JSON 使用本插件的文件结构，不支持 Firefox JSON/JSONLZ4 专用备份：

```json
{"format":"quokmark-bookmarks","version":1,"items":[{"title":"工作","children":[{"title":"GitHub","url":"https://github.com/"}]}]}
```

Markdown 使用标准嵌套列表，无链接的列表项表示目录，有链接的列表项表示书签；目录名称可加粗。不使用标题表示目录，书签下不能包含子项。例如：

```markdown
- **工作**
  - [GitHub](<https://github.com/>)
  - **资料**
    - [MDN](<https://developer.mozilla.org/>)
```

HTML 兼容 Chrome、Edge、Firefox 的浏览器书签交换格式，处理名称、网址、目录层级和顺序；不迁移 favicon、日期、标签、关键字及浏览器特殊根目录身份。Firefox 分隔符不导出，HTML 导入预览会显示忽略数量。
