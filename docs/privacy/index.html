中文

QuokMark 是用于通过键盘访问和整理浏览器原生书签的扩展，无需注册或登录。

数据如何使用

扩展读取浏览器书签名称、网址和目录结构，以显示、搜索、打开、重命名、移动和删除书签。搜索在本地执行。书签修改直接作用于浏览器原生书签库，删除操作需要确认且不可通过本扩展撤销。

扩展在浏览器本地扩展存储中保存语言、主题、目录折叠状态及界面滚动偏好。书签仍由浏览器管理；如果用户启用了浏览器账户同步，书签同步由浏览器及其服务商依据其隐私政策处理。QuokMark 不提供独立的云同步服务。

用户使用 yy 时，扩展仅把选中书签的网址写入系统剪贴板。扩展不读取剪贴板内容。剪贴板内容可能被操作系统或用户的剪贴板同步设置处理。

网站图标通过浏览器的 favicon 接口取得，不向第三方图标服务发送书签网址。用户主动打开书签后，浏览器会访问目标网站，网站自身的数据处理适用该网站的隐私政策。

数据传输与第三方

QuokMark 没有自建数据服务器、分析统计、广告、跟踪 SDK 或远程执行代码。书签、搜索词和界面偏好不由扩展上传给发布者或第三方，不出售或共享这些数据。扩展不读取网页内容、浏览历史或密码。

权限

bookmarks：读取和管理原生书签。

storage：保存本地界面偏好。

favicon：显示浏览器保存的网站图标。

clipboardWrite：在用户主动执行 yy 时复制书签网址。

保留与删除

界面偏好保留在本地扩展存储中，卸载扩展时由浏览器清理。卸载扩展不会删除浏览器原生书签，也不会撤销之前已经执行的书签修改或清空系统剪贴板。

如通过邮件联系支持，发布者会使用您主动提供的邮箱及问题内容回复请求；请勿发送不必要的私人书签、密码或其他敏感数据。可联系 methodref@outlook.com 请求删除支持邮件中的个人信息。

如后续版本改变数据处理方式，本政策将同步更新。如有隐私问题，请联系 methodref@outlook.com。

English

QuokMark is a keyboard-driven tool for accessing and organizing native browser bookmarks. No registration or sign-in is required.

Local processing

The extension reads bookmark titles, URLs and folder structure to display, search, open, rename, move and delete bookmarks. Searches run locally. Edits affect the browser's native bookmark store. Deletion requires confirmation and cannot be undone within this extension.

Language, theme, folder collapse state and scrolling preferences are saved in local extension storage. Bookmarks remain managed by the browser. If browser account sync is enabled, the browser and its provider handle bookmark synchronization under their own privacy policies. QuokMark does not operate a separate cloud sync service.

When you press yy, QuokMark writes only the selected bookmark URL to the system clipboard. It does not read clipboard contents. Your operating system or clipboard synchronization settings may process copied text.

Website icons are obtained through the browser favicon API, without sending bookmark URLs to third-party icon services. Opening a bookmark visits the selected website; that website's own privacy policy applies.

Transmission and third parties

QuokMark has no publisher-operated data server, analytics, advertisements, tracking SDKs or remotely executed code. The extension does not upload bookmark data, search terms or preferences to its publisher or third parties, and does not sell or share that data. It does not read web page content, browsing history or passwords.

Permissions

bookmarks: read and manage native bookmarks.

storage: save local preferences.

favicon: display browser-provided site icons.

clipboardWrite: copy a bookmark URL when the user invokes yy.

Retention and control

Preferences remain in local extension storage until removed by the browser, including during uninstallation. Uninstalling QuokMark does not remove native bookmarks, reverse previous bookmark edits or clear the system clipboard.

If you email support, the publisher uses the email address and information you voluntarily provide to answer your request. Avoid sending private bookmarks, passwords or unnecessary sensitive information. To request deletion of personal information in support correspondence, contact methodref@outlook.com.

This policy will be updated if a future version changes data practices. Privacy questions can be sent to methodref@outlook.com.
